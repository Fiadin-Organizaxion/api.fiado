# 📱 FIADIN

Sistema mobile para controle de fiados em mercadinhos e pequenos comércios.

O FIADIN permite registrar clientes, lançar dívidas (fiados), identificar qual funcionário realizou o registro e oferecer controle total ao dono do estabelecimento.

---

## 🚀 Objetivo do Projeto

Desenvolver um aplicativo Android utilizando **Kotlin** com backend em **TypeScript**, implementando:

- Autenticação com controle de acesso
- Registro de clientes
- Registro de fiados
- Auditoria de ações (quem registrou cada dívida)
- Diferenciação de permissões entre DONO e FUNCIONÁRIO
- Banco de dados online

O projeto tem como foco arquitetura profissional e boas práticas de desenvolvimento.
